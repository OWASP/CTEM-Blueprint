# Security Policy

Do **not** report secrets, customer information, private exploit details, or nonpublic security findings through public issues.

For a suspected security issue concerning the **CTEM Blueprint repository or its project-managed systems**, use the official [OWASP Contact and Support channel](https://owasp.org/contact) and request confidential routing to the CTEM Blueprint project leadership. If GitHub private vulnerability reporting has been enabled for this repository, it may also be used, but availability has not been independently verified.

For vulnerabilities in third-party products, use the affected product owner's disclosure channel rather than this project's issue tracker.

The project presently publishes draft methodology documentation, not a supported production security product. The project leadership should coordinate private triage and responsible disclosure without publicly exposing report details.
