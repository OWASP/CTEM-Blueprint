# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately and responsibly.

Use the repository's security reporting mechanisms or contact the maintainers directly.

## Disclosure process

- Validate the report and assess impact.
- Coordinate a fix and responsible disclosure timeline.
- Publish a security advisory when appropriate.

## Supported versions

This repository is currently treated as a draft blueprint and should be evaluated for current operational use before production deployment.
