# Contributing

Contributions are welcome.

## How to contribute

1. Fork the repository.
2. Create a dedicated feature branch.
3. Add or improve documentation, mappings, playbooks, or validation guidance.
4. Submit a pull request with a clear summary of the change.

## Review expectations

- Keep content factual and actionable.
- Prefer clear, concise security-focused documentation.
- Maintain consistent naming and formatting.
